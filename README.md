# ニコニコ車載動画 初投稿年別＆活動状況ビューアー

ニコニコ動画の車載動画ジャンルにおける、初投稿年別（2016年、2021年、2023年、2025年）の投稿者データベースおよび直近1年間の活動状況分析アーカイブです。

## 主な機能
- **初投稿年フィルタ**: 2016年 / 2021年 / 2023年 / 2025年 / すべて をタブ・統計カードからワンクリックで切り替え
- **活動状況フィルタ**: 「すべて」「活動中（直近1年投稿あり）」「休止中」の3段階で切り替え
- **インクリメンタル検索**: 投稿者名、初投稿・最新投稿タイトル、sm番号、ユーザーIDによるリアルタイム複数ワードAND検索
- **ユーザーアイコン表示**: ニコニコ動画の公式アバターアイコンを自動生成・表示
- **ニコニコ連携**: 動画リンク（`smXXXX`）やユーザーマイページへの直接リンク
- **ソート機能**: 最新投稿日時 / 初投稿日時 / 投稿者名による並び替え
- **レスポンシブデザイン**: PC・スマートフォン両対応

## データの再ビルド方法
元データCSV（`nico-analyzer/results` 配下）を更新後、以下を実行してデータを再生成できます。

```bash
uv run --with pandas build_data.py
```

## ローカルでのプレビュー
`index.html` をブラウザで直接ダブルクリックして開くか、ローカルWebサーバーを起動して確認できます。

```bash
# Pythonの簡易サーバーで起動する場合
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages での公開手順
1. このフォルダを GitHub の新規リポジトリにプッシュします。
2. GitHub リポジトリの **Settings > Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択し、Branch を `main` / `root` に設定して **Save** します。
4. 数分で `https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/` で世界中に公開されます。

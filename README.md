# ニコニコ ボイロ（広義）車載動画 初投稿年別＆活動状況データベース

ニコニコ動画のボイロ（広義）車載動画ジャンルにおける、歴代初投稿者（2007年〜現在）の初投稿・最新動画および活動状況の分析・閲覧ができるWebデータベースです。

👉 **Webサイト公開URL**: [https://estshorter.github.io/nico-onboard-viewer/](https://estshorter.github.io/nico-onboard-viewer/)

---

## 主な機能
- **全年度対応の初投稿年フィルタ**: 2007年〜2026年の全年度からワンクリックで絞り込み
- **活動状況フィルタ**: 「活動中（直近1年投稿あり）」「すべて」「休止中」の3段階切り替え
- **活動状況サマリー**: 選択中の年度における総人数・活動中人数・活動継続率（%）とプログレスバーを連動表示
- **インクリメンタル検索**: 投稿者名、初投稿・最新投稿タイトル、sm番号、ユーザーIDによる複数ワードAND絞り込み検索
- **ユーザーアイコン表示**: ニコニコ動画公式アバターアイコンの自動取得＆フォールバック表示
- **ニコニコ公式連携**: 動画視聴ページ（`smXXXX`）やユーザーマイページへの直接リンク
- **ソート機能**: 最新投稿日時 / 初投稿日時 / 投稿者名による並び替え
- **非表示・オプトアウト機能**: 特定ユーザーの非表示リクエストに対応（`excluded_users.json` による管理・フロントエンドでの除外）
- **レスポンシブデザイン**: PC・スマートフォン両対応

---

## データ集計について
- **データ出典**: [ニコニコ動画 『スナップショット検索API v2』](https://site.nicovideo.jp/search-api-docs/snapshot)
- **データ集計基準日**: **2026年8月15日**
- **「活動中」の定義**: 集計基準日（2026年8月15日）から遡って1年以内（2025年8月15日以降）にボイロ（広義）車載動画ジャンル等で動画投稿実績が確認できたユーザーを示します。
- **初投稿者の抽出条件（対象タグ）**:
  ニコニコ動画において以下のいずれかのタグ（OR条件）が登録されている動画を対象として初投稿者を抽出しています：
  1. `VOICEROID車載`
  2. `VOICEPEAK車載`
  3. `CeVIO車載`
  4. `ソフトウェアトーク車載`
  5. `A.I.VOICE車載`
  6. `VOICEVOX車載`
  7. `ガイノイドTalk車載`
  8. `Coefont車載`
  9. `結月ゆかり車載`
  10. `弦巻マキ車載`
  
  ※「ゆっくり車載」等のみが付与されている動画は本集計の対象外です。

## 特定ユーザーの非表示設定（オプトアウト）について
本データベースへの掲載取り下げ・非表示をご希望の投稿者様は、リポジトリのIssueまたは作者連絡先（[X: @irisevir](https://x.com/irisevir)）までお申し出ください。
非表示対象ユーザーは `excluded_users.json` および `app.js` の除外リストで管理され、集計・検索・一覧表示から完全に除外されます。
